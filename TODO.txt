Bug in mutate(): infinite loops are possible
If the mutation count exceeds the number of available weights in a layer, this loop can run forever.
For example, if a layer has 15 weights and your mutation process tries to mutate all 15, it can work. But if it tries to mutate 16 weights in that same layer, it will never find another unique index.
